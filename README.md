# ha-hero

During setup, use **Excluded calendar words** to hide events with matching words in their titles. Enter one or more words separated by commas, for example `Senior, Junior`. Matching ignores case and uses whole words: `Senior` hides “Senior Camp” but does not hide “Seniors Camp”. The entire event is hidden.

You can edit or clear the exclusions later in the Hero integration’s options. Leave the field blank to disable word filtering. The existing week-number filter works independently.
